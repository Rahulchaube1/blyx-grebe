# Grebe starter

Build a repeatable keyset page and return the exact next cursor.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Grebe** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
1
3
30
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/grebe) · [View the release](https://github.com/Rahulchaube1/blyx-grebe/releases/tag/v0.1.0)
